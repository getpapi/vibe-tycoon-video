# Shipaton demo plan — Vibe Tycoon

**Target:** 1080 × 1920 portrait · **Planned duration:** 110 seconds · **Status:** footage not captured; timing is a guide, not an approved cut.

| Time | Capture on the phone | Editing note |
|---|---|---|
| 0–3 s | Start directly on the live game screen and show one immediate player action. | Open on functioning gameplay; no logo-only intro. |
| 3–28 s | Show the homepage prompt loop, the player's input, and visible job progress or payout. | Use one continuous, readable device capture. |
| 28–48 s | Show the shipped path from prompting to delegating work to agents. | Include only interactions that work in the release build. |
| 48–73 s | Show a real progression or upgrade interaction and its visible result. | Do not imply a reward or progression state the build does not grant. |
| 73–98 s | Show a product/client outcome and the resulting game state. | Keep the screen legible; avoid third-party marks in the capture. |
| 98–107 s | Show one other verified, distinctive shipped feature. | Choose the feature after the final device capture; omit if it cannot be demonstrated cleanly. |
| 107–110 s | End on the actual game screen with a brief Vibe Tycoon title. | No third-party logo, unlicensed music, or fabricated UI. |

## Capture and edit gates

- Record Vibe Tycoon actually running on the supported phone. Use the production or submission build that judges can install; do not substitute a browser mockup, preview render, or reconstructed UI.
- Review every interaction against the build used for submission. Re-capture any screen that no longer matches current behavior.
- Use game audio only if it is cleared for publication; otherwise keep the edit silent. Add no stock footage, logos, music, screenshots, or other third-party material without permission.
- Keep the complete exported video below 120 seconds. Leave the target at 110 seconds so the final edit has room for trims.
- Export locally first. Public YouTube/Vimeo hosting and submission-form entry are separate steps and need owner approval for the exact video and destination.
